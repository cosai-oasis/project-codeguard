---
name: codeguard
description: Guides secure implementation, vulnerability remediation, and security review. Use when the request explicitly asks for security hardening, vulnerability remediation, or security review, or when code or configuration handles untrusted or external data, dynamic execution, authentication, sessions, authorization, privilege, credentials, secrets, cryptography, files or parsers, network listeners or destinations, external service integrations, security logs or externally visible errors, dependencies, builds, deployment, or concurrent access to protected state. Supports domain guidance within repository audits; not audit orchestration, compliance assessment, penetration testing, prose, or routine work outside these surfaces.
---

Prioritize security and avoid introducing vulnerabilities.
